# Horizonte Talento · Explorador de Aula · v0.8.1 (prototipo para revisión)

Basado en v0.8.0, con **una sola demostración ficticia** y Secundaria limitada a 1.º–4.º de ESO.

## Novedad de esta revisión

Se incorpora «¿Quieres profundizar con IA?» **al final de los informes individuales y grupales**. Incluye instrucciones para descargar el PDF, tres prompts completos (Intereses, Personalidad y preferencias, Sensibilidades y bienestar), un botón para copiarlos y una advertencia explícita sobre protección de datos.

Los tres prompts incorporan instrucciones diferenciadas para **Infantil, Primaria y ESO**, y se ajustan al carácter individual o grupal del informe. El apartado muestra solo como seleccionables los módulos incluidos en la exploración.

## Privacidad y límites

- No se integra ninguna IA, cuenta, API ni envío automático a terceros.
- El PDF **no se anonimiza automáticamente**. Es responsabilidad del usuario retirar toda información identificativa y comprobar que el servicio externo está autorizado antes de adjuntarlo. Si no lo está, debe usar únicamente datos no personales o un ejemplo ficticio.
- Los prompts orientan actividades pedagógicas; no diagnostican.
- El apartado de IA no se añade al PDF ni a la impresión, para que el informe siga siendo legible.
- Cuestionarios, criterios, motor de cálculos, resultados, recomendaciones y sesión se mantienen iguales que en v0.8.0.
